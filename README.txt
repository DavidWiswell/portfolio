DAVID WISWELL PORTFOLIO SITE

Open index.html locally to preview.

For GitHub Pages:
1. Upload every file in this folder to the repository root.
2. In GitHub repository Settings → Pages, deploy from the main branch/root.
3. index.html will be the home page.

Page order:
Home → About → Projects → Selected Concepts → Produced Work → Contact
